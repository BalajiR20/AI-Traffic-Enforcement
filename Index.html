Architecture Context: Unlike traditional systems that constantly run resource-heavy OCR models on every frame, this project uses a modular pipeline. Continuous lightweight object detection and multi-object tracking identify candidate vehicles, which undergo temporal validation before triggering OCR, evidence package creation, and database logging.

🧠 Violation Detection Engines & Temporal Validation

Combining specialized deep learning models with geometric rule engines and temporal persistence logic.

Detection Logic & Noise Mitigation: The system identifies four major traffic violations using two distinct approaches: specialized object detection models (for helmets and riders) and geometric spatial rules (for red-light jumping and wrong-way trajectories). To eliminate transient detection errors or occlusion noise, candidates must satisfy strict temporal persistence across consecutive frames.

Deep Learning Model Model: YOLOv8n Fine-Tuned

🪖 1. Riding Without a Helmet

Utilizes a YOLOv8n model fine-tuned on the AI City Challenge Track-5 Helmet Dataset. Detects two-wheeler riders and determines helmet presence. Associates unhelmeted head detections directly with the tracked vehicle ID.

Validation Rule: Requires rider without helmet to be detected continuously across N consecutive frames before generating ANPR trigger.
Geometric Rule Engine Model: YOLOv8n + Tracking

🚦 2. Red Light Jumping

Analyzes vehicle trajectories relative to pre-configured stop-line boundaries and traffic signal states detected in real-time. Eliminates the need for specialized deep learning retraining for every unique camera angle.

Validation Rule: Triggered when vehicle bounding-box centroid crosses the stop boundary while signal state is evaluated as RED.
Geometric Rule Engine Model: ByteTrack Trajectory

⛔ 3. Wrong-Way Driving

Tracks vehicle displacement vectors across frames using ByteTrack identities. Compares observed motion direction against pre-defined directional vector boundaries assigned for the lane ROI.

Validation Rule: Direction vector cosine similarity must remain negative relative to normal traffic flow for multiple tracking cycles.
Object Association Model: YOLOv8n Core

🛵 4. Triple Riding Detection

Evaluates spatial overlap and bounding-box co-location between detected person/rider objects and motorcycles. Flags cases where rider count associated with a single motorcycle ID exceeds two.

Validation Rule: Person counts bound to motorcycle track ID must evaluate ≥ 3 across consecutive frames.

⚡ Event-Driven Efficiency Analysis

Comparing resource overhead of continuous ANPR/OCR execution versus event-driven execution.

Efficiency Design: Deep learning OCR engines like PaddleOCR and plate localization networks consume high GPU compute cycles. By deferring ANPR until a violation candidate passes multi-frame temporal validation, the overall frame processing burden is reduced by up to 80% under standard traffic conditions, enabling edge deployment.

📊 System Specifications, Limitations & Future Scope

Overview of technological stacks, dataset backings, prototype scope, and upcoming developments.

Evaluation & Technical Context: The prototype demonstrates complete integration from continuous OpenCV stream capture down to Fast API database logging. Below is a detailed breakdown of technologies used, specialized training datasets, current operational bounds, and strategic enhancements planned for edge deployment.

💻 Technology Stack

  • Detector: YOLOv8n (Ultralytics)
  • Tracking: ByteTrack
  • OCR Engine: PaddleOCR
  • Backend API: FastAPI (Python)
  • Database: SQLite (Prototype)
  • Security Hashing: SHA-256 Hashing

📁 Specialized Datasets

AI City Challenge Track-5:

Used for fine-tuning helmet violation identification models under diverse traffic density and lighting.

Indian Licence Plate Dataset:

Fine-tuned YOLOv8n plate detector specialized in standard and custom Indian vehicle registration plate formats.

⚖️ Traditional vs Proposed

Manual CCTV Monitoring: High operator fatigue, poor scalability, delayed vehicle registration lookup.
Proposed AI + Human: Automatic multi-violation detection, temporal false positive filtering, 1-click review portal.

⚠️ Current Prototype Bounds & Limitations

  • Camera position and lighting dependency (glare, extreme nighttime shadow).
  • Vehicle occlusion during heavy rush-hour traffic congestion.
  • License plate OCR ambiguity caused by dirty, damaged, or severely tilted plates.
  • Geometric zone calibration required for new camera installation angles.

🚀 Future Expansion Roadmap

  • Expanded violations: Seatbelt compliance, mobile phone usage, illegal parking.
  • Edge device optimization with GPU acceleration (NVIDIA Jetson / TensorRT).
  • Automated retraining loop: Human rejection cases fed back to dataset pipeline.
  • Government transport database integration via secure REST endpoints.
